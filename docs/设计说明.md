# EAI 设计说明

## 1. 核心命题

**模型是引擎，记忆和人格是灵魂。** 不训练、不微调，只做"模型外面的记忆"；换任何模型（Claude / Codex / 本机小模型），接上同一套记忆数据，就是同一个管家。

要成立的三件事（均有实测支撑）：

1. 记忆可无限增长（磁盘级），会话注入量恒定（只取 top-k，实测 1k→1368 字符、10k→1383 字符）；
2. 记忆自动持续写入（白天记录、夜里固结）；
3. 人格可以从记忆里长出来（画像自动合成、纠错覆盖、承诺追踪）。

## 2. 架构：三层记忆 × 三个循环

```
引擎（随时可换）: Claude / Codex / 本机模型
    ↑ 五个接入面：开场简报 · 按需回忆 · MCP 工具 · 命令行 · 每日固结
    ↓
三循环：记录（白天） → 固结（夜里） → 回忆（随问随取）
    ↓
三层记忆：
  核心 core/     身份守则 · 主人画像 · 承诺台账（可手改）
  语义 memory.db 事实/偏好/纠错/决定/承诺/项目/做法（SQLite + FTS5）
  情景 journal/  原始经历，只增不改、永不删除
```

自下而上"提炼"（经历→条目→人格），自上而下"回忆"（检索→注入）。

## 3. 数据模型

记忆条目（`memory.db: memories` 表）关键字段：

| 字段 | 说明 |
|------|------|
| kind | fact 事实 / preference 偏好 / correction 纠错 / decision 决定 / promise 承诺 / project 项目动态 / skill 做法 / episode 经历 |
| scope | 项目名或 general |
| importance | 0–1；纠错 0.9、偏好 0.8、事实 0.6… |
| ts / updated_ts | 事件时间 / 最后更新（事件时间来自源会话日期，不是入库日） |
| supersedes / superseded_by / status | 覆盖链；active / archived **永不物理删除** |
| use_count / last_used_ts | 被回忆次数，用于"用则强化" |

检索索引：FTS5 表，中文按**二元分词**进索引（"记忆系统"→`记忆 忆系 系统`）。

## 4. 关键算法

### 4.1 检索打分（回忆 = 相关 × 重要 × 新近）

```
score = 0.55·相关度 + 0.30·重要度 + 0.15·新近度   (+0.08 若 scope 命中当前项目)
相关度 = 查询词元在条目中的覆盖率（绝对口径，阈值才有意义）
新近度 = 0.5^(天数 / 半衰期)：纠错/偏好 3650 天，承诺 900，决定/做法 720，事实 540，项目 240，经历 60
```

**用则强化**：命中即 use_count+1、重要度小幅提升；提升幅度随使用次数递减（防"最早露头者"滚雪球锁死席位）。

### 4.2 中文检索（bigram）

FTS5 默认切不好中文。方案：入库/查询同做二元切分，检索梯队为 **短语 → 全词与 → 任一词 → LIKE 兜底**；结果按覆盖率排序、bm25 相关序作同分裁决。中文短语、缩写、中英混排均覆盖（单测有专测）。

### 4.3 固结流水线（每晚）

1. **收料**：采集器读 Claude/Codex 转录 → `inbox/`（文件名带内容指纹 `{会话id}.{sha8}.md`——会话续写产生新版本文件、不覆盖旧版，否则续写内容永远漏记）；
2. **提炼**：按 ~4000 字切块喂本机 LLM（默认 Ollama qwen 系；失败自动退纯规则），产出结构化候选；
3. **查重**：与库内最相近条目比对——有 LLM 仲裁时按 same/update/conflict/different 处理；
4. **两条铁律**：**仲裁不可用一律新增**（宁可重复，绝不静默错并）；**合并不丢内容**（互不包含的正文拼接而非"取更长"）；
5. **落库**：写库 + 追加情景日志 + 写当日摘要（白话语）；事件时间回填（用会话日期，保新近度维度）；
6. **刷新人格**：重写画像与承诺台账（承诺由 LLM 复核是否已被后续事实兑现）；旧版存 versions/。

### 4.4 每日一条龙（`eai day`）

收料 → 固结 → 刷画像 → 刷新简报快照 → git 留痕。可注册为计划任务每晚自动跑。

## 5. 工程与安全守则

- **零第三方依赖**（纯标准库）——Python 3.8+ 直接跑；存储用 SQLite（WAL）。
- **id 抗撞**：时间戳 + 随机16位 + 进程内单调计数（批量入库不撞 UNIQUE）。
- **归档不占候选池**：FTS 查询直接 JOIN 过滤 active（覆盖链累积不拖慢检索）。
- **只看不用**：开场简报不触发强化（强化只属于主动查询），评测强制不强化、可复跑。
- **隐私**：全本地；固结默认本机 Ollama；`memory/` 默认不进 git；无遥测。
- **可停**：所有自动化（钩子/计划任务/MCP）都可一键撤销，记忆数据独立保留。

## 6. 已知简化（欢迎共建）

- 检索为 bigram+FTS 的词法检索，尚无向量语义检索（接口已预留）；
- 无同音/形近错别字映射；
- 重要度无周期性衰减（仅有"强化递减"）；
- confidence 字段已入库但未参与打分。
