# 双机同步（让两台电脑共用同一个管家）

EAI 的全部家当就是一个文件夹。把它完整拷到第二台电脑，装上 Python，
双击 `tools\install.bat`（装完后可选"不回放历史"）即可——记忆、人格、承诺全在。

## 手动同步（推荐，稳）

1. 在"写入方"电脑跑一次 `eai day`，确保全部落盘；
2. 整个文件夹拷到另一台（U 盘/局域网/网盘均可）；
3. 第二台继续用。

## git 同步（要增量、要历史时）

EAI 本身就是 git 仓库。注意：

- **同一时间只让一台电脑跑固结**（`memory.db` 是二进制，双边同时写会打架）；
- 换机器前先 `git pull`，用完 `git push`；
- 默认 `.gitignore` 把 `memory/` 排除在外——若要跨机同步记忆，把 `memory/` 从 `.gitignore` 里放出来，且**只推私有仓库**（记忆是隐私）。

## 只要备份"记忆"

只拷 `memory\` 文件夹即可（代码可从本仓库重新 clone）。其中最关键的是
`memory.db`（记忆库）与 `core\`（身份与画像）。
