# EAI 使用手册

> 管家住在你 clone 下来的这个文件夹里。所有记忆在 `memory/`，全在本机、只增不丢。

## 快速开始

```bash
# Windows
双击 tools\install.bat
# macOS / Linux
bash tools/install.sh
```

装完即可用。日常入口：

| 想干什么 | 怎么做 |
|----------|--------|
| 打开管家菜单（Windows） | 双击 `tools\管家.bat` |
| 让管家记住一件事 | `eai remember "要记住的话"` |
| 查一件事 | `eai recall "关键词"` |
| 翻原始经历 | `eai recall --journal "关键词"` |
| 看管家"记得你什么" | `eai brief` |
| 今日一条龙 | `eai day` |
| 跟管家对话 | `eai chat` |
| 成长报告 | `eai growth --since 7d` |
| 体检 | `eai doctor` |

## 命令一览

| 命令 | 作用 |
|------|------|
| `eai init` | 初始化（安装器已自动跑过） |
| `eai remember "…" -k preference` | 记一条（kind：fact/preference/correction/decision/promise/project/skill/episode） |
| `eai recall "…" -k 8` | 查记忆；命中会强化（用得越多记得越牢） |
| `eai brief --scope 某项目` | 打印开场简报 |
| `eai journal add/tail` | 情景日志（原始经历流水） |
| `eai harvest` | 采集 Claude/Codex 会话转录 → 收料区 |
| `eai consolidate --model quality` | 固结收料 → 记忆库 |
| `eai day` | 收料+固结+刷画像+快照+git 留痕，一键 |
| `eai digest` | 看某天"我记住的事" |
| `eai growth` | 成长报告 |
| `eai stats` | 统计（条数/体积/收料覆盖率） |
| `eai done <id>` | 承诺销账 |
| `eai mcp` | 启动 MCP 服务（接口模式） |

## 每晚自动（可选）

- Windows：安装器可注册计划任务（每天 21:30 跑 `eai day`）；也可双击
  `tools\register_daily_task.bat` / `tools\unregister_daily_task.bat`。
- Linux/macOS：把安装器打印的那行 crontab 加进去即可。

## 接进每次会话

1. **Claude Code**：安装器自动三件套——SessionStart 钩子（实时简报）+ CLAUDE.md 快照导入（兜底）+ MCP 工具。已用全新空白会话验证：开场即能报出你的项目与红线。
   - 排障记录：Claude Code 执行钩子走 **PowerShell**（Windows），命令必须 PowerShell 语法；本项目用 `shell: "powershell"` + `tools/hook_boot.bat` 固化，勿改回 bash 写法。
2. **其它 MCP 客户端**：命令配 `python <仓库路径>/src/eai/mcp_server.py`，
   得到 `recall` / `remember` / `memory_stats` 三个工具。

## 记忆在哪

```
memory\
├─ memory.db      记忆库（SQLite，全文检索）
├─ journal\       情景日志（原始经历，只增不改）
├─ inbox\         收料区（转录 → 待固结）
├─ digests\       每天"我记住的事"（白话语）
└─ core\          身份守则 / 主人画像 / 承诺台账（identity.md 可直接改）
```

`memory/` 默认不进 git；要双机同步见 `docs/双机同步.md`。

## FAQ

1. **没有 Ollama？** 固结自动退纯规则，流程不中断；装上 Ollama 后自动升级。
2. **中文乱码？** 走 `tools/*.bat` 启动（内置 UTF-8），或设 `PYTHONUTF8=1`。
3. **记错了？** `eai remember "更正：……" -k correction`，下次固结以新为准，旧条归档备查。
4. **想停用？** `python tools/install.py --uninstall` 撤销全部接入；记忆保留。
